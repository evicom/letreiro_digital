# 🎯 Letreiro Digital Personalizável

Um aplicativo web moderno e responsivo que exibe mensagens em um painel digital com efeito rolante (marquee).  
Totalmente customizável com opções de **fonte** (incluindo estilo placar eletrônico), **tamanho**, **velocidade** e **cores**.

![Preview](https://via.placeholder.com/800x400/000/ffcc00?text=Letreiro+Digital+em+Ação)

---

## 🚀 Funcionalidades

- ✅ Texto rolante contínuo (efeito marquee)
- ✅ 7 opções de fontes, incluindo **Orbitron** (estilo placar eletrônico)
- ✅ Ajuste de tamanho do texto (responsivo em `vw`)
- ✅ Controle de velocidade da rolagem (5 a 60 segundos por ciclo)
- ✅ Seleção de cores para:
  - Texto (com efeito neon)
  - Fundo do painel
  - Borda e brilho externo
- ✅ Design totalmente responsivo (funciona em celulares, tablets, TVs e desktops)
- ✅ Código 100% **vanilla** (HTML, CSS e JS puros) – sem dependências externas

## 🛠️ Como usar

### 1. Opção mais rápida (direto no navegador)
Baixe o arquivo [`index.html`](index.html) e abra-o em qualquer navegador moderno (Chrome, Edge, Firefox, Safari).

### 2. Opção GitHub Pages (hospedagem gratuita)
1. Crie um novo repositório no [GitHub](https://github.com).
2. Envie os arquivos `index.html` e `README.md` para o repositório.
3. Acesse **Settings** → **Pages** → escolha a branch `main` e a pasta `/root`.
4. O site estará disponível em `https://seu-usuario.github.io/nome-do-repositorio`.

---

## 🎮 Instruções de uso

1. Digite a mensagem no campo **Texto** e pressione **Enter** ou clique em **Atualizar**.
2. Escolha a **Fonte** desejada (destaque para a opção *Orbitron – Placar Eletrônico*).
3. Ajuste o **Tamanho** e a **Velocidade** com os sliders.
4. Personalize as **Cores** do texto, fundo e borda usando os seletores.
5. Divirta-se! O letreiro responde instantaneamente a cada ajuste.
